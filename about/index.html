사이트 소개

Champions Helper는 포켓몬 챔피언스를 실제로 플레이하는 한 명의 유저가 직접 개발·운영하는 비공식 보조 도구이자 정보 사이트입니다.

왜 만들었나

포켓몬 챔피언스의 랭크 배틀은 결국 숫자 게임입니다. 상대 포켓몬의 스피드가 나보다 빠른지, 내 기술이 확정 1타인지, 상대의 최고 화력을 내가 버틸 수 있는지 — 이 계산을 매 턴 암산으로 하는 것은 불가능에 가깝습니다. 처음에는 개인용으로 배틀 화면을 인식해 데미지를 자동 계산하는 프로그램을 만들었고, 쓰다 보니 "이건 다른 유저들에게도 필요하겠다" 싶어 무료로 공개한 것이 이 사이트의 시작입니다.

지금은 데스크탑 앱과 함께, 브라우저에서 바로 쓰는 데미지 계산기·파티 빌더·도감·배틀데이터, 그리고 실전 데이터를 분석한 공략 가이드까지 운영하고 있습니다. 전부 무료이며 계정 가입도 필요 없습니다.

무엇을 제공하나

  • Champions Helper 데스크탑 앱 (Windows) — 배틀 화면을 자동 인식해 상대 파티 전원에 대한 내 기술 데미지, 확정 타수, 스피드 비교를 실시간 표시. 메가진화·날씨·랭크 변화·상태이상까지 자동 반영.
  • 웹 데미지 계산기 — 게임과 동일한 공식(레벨 50·개체값 31·챔피언스식 노력치)으로 검증된 계산. 프로그램 설치 없이 사용.
  • 도감 (235종) — 종족값·타입 상성·특성·메가진화, 그리고 실전 채용 기술과 채용률.
  • 배틀데이터 — 싱글·더블 랭크배틀 사용률 순위. 12시간마다 자동 갱신.
  • 공략 가이드 — 채용률 데이터에 근거한 메타 분석, 스피드 라인 표, 노력치 배분, 파티 구성법 등.
  • 파티 공유 게시판 — 유저들이 실측 전적과 함께 파티를 공유하는 공간.

데이터는 어디서 오나

정확성이 이 사이트의 존재 이유이므로, 출처를 투명하게 밝힙니다.

  • 종족값·기술·특성 데이터 — 게임 내 값을 직접 확인·역산해 구축하고, 검증된 공개 데이터베이스와 교차 확인합니다. 계산식은 실제 게임 수치와 대조해 검증했습니다.
  • 사용률·채용률 통계 — 포켓몬 챔피언스 공식 랭크 배틀 순위 데이터를 직접 집계해 사용합니다. 사용 순위·기술·특성·지닌도구·성격·노력치 배분·팀 조합이 모두 같은 원본에서 나오며, 각 페이지에 출처와 산출 시각(KST)을 표기합니다. 12시간마다 자동 수집·갱신됩니다.
  • 스프라이트·명칭 — Nintendo, Game Freak, The Pokémon Company에 권리가 있는 자료로, 팬 사이트로서 식별 목적으로만 사용합니다.

운영 원칙

  • 게임과 다른 숫자를 보여 주지 않는다 — 계산 결과가 게임 실측과 다르면 버그로 취급하고 고칩니다. 유저 제보로 수정된 계산(프리즈드라이 상성, 사이코쇼크 판정 등)은 즉시 전체 도구에 반영됩니다.
  • 추측과 데이터를 구분한다 — 통계에 근거한 내용은 수치·시점·출처를 밝히고, 편집자 판단은 판단임을 밝힙니다.
  • 무료 유지 — 도구와 정보는 계속 무료로 제공합니다.
