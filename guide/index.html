포켓몬 챔피언스 가이드

게임 입문부터 데미지 계산 공식, 실전 채용률 데이터로 쓰는 메타 분석 칼럼까지. 배틀에 필요한 핵심을 한글로 정리했습니다.

공략·칼럼

공식 랭크배틀 순위 데이터를 직접 집계해 쓰는 분석 글입니다. 승패 기록·결정타 분포·팀 조합처럼 채용률만으로는 안 보이는 축까지 함께 다룹니다.

데이터 분석

무엇에 죽는가 — 패배 기록으로 본 진짜 위협

상위 50종이 실제로 어떤 기술에 쓰러졌는지 전수 집계했습니다. 지진 하나가 격침의 19.3%. 채용률 순위가 아니라 패배 기록이 말하는 위협 순서를 정리합니다.

 데이터 분석

채용률이 알려주지 않는 것 — 실제로 경기를 끝내는 기술

승리를 확정한 마지막 기술 분포를 채용률과 대조했습니다. 유턴은 왜 결정타가 못 되고, 불릿펀치는 왜 핫삼 승리의 67%를 마무리하는가.

 데이터 분석

상성 지도 — 확실히 이기는 상대와 지는 상대

승리·패배 상대 기록을 교차해 상위 20종의 유불리를 지도로 만들었습니다. 타입 상성표가 알려주지 않는 실전 매치업.

 데이터 분석

지닌도구 메타 — 먹다남은음식이 1위인 이유

상위 50종 도구 채용률 전수 집계. 1~3위가 전부 버티는 도구인 이유와, 기합의띠 9.7%가 확정 1타 계산에 뜻하는 것.

 데이터 분석

노력치 66의 현실 — 상위 50종의 실제 배분

스탯당 32·합계 66이라는 제약이 빌드를 어떻게 규정하는가. 상위 50종의 96%가 같은 구조를 택한 이유를 계산으로 설명합니다.

 실전 판단

상대 특성 맞히기 — 복수 특성 확률표

보이지 않는 상대 특성을 어떻게 가정할 것인가. 채용률 90% 이상은 확정 취급, 70% 미만은 추측 금지 — 종별 확률표와 판단 기준.

 메타 분석

싱글과 더블은 다른 게임 — 순위 격차 데이터

키키링 176위→8위, 하마돈 4위→130위. 같은 포켓몬이 100계단 넘게 움직이는 이유를 광역기·서포트·장기전 세 축으로 분석합니다.

 데이터 분석

성격 선택의 실제 — 최속이 정답이 아닌 경우

상위 50종 중 스피드 상승 성격은 28%뿐입니다. 챔피언스의 노력치 구조가 성격 선택을 어떻게 바꿔 놓았는지 실수치 계산으로 확인합니다.

 파티 구성

실제로 함께 쓰이는 코어 — 팀 조합 데이터

공식 팀 조합 기록에서 서로를 지목한 쌍만 추렸습니다. 한카리아스·따라큐가 아무 파티에나 들어가는 이유와 약점 겹침을 피하는 법.

 실전 판단

선출 전 30초 — 상대 파티에서 읽어내는 것

제한된 시간에 무엇부터 볼 것인가. 땅 기술 → 확정 불리 → 스피드 라인 → 특성 → 구조 → 우선도 순으로 훑는 실전 체크리스트.

 메타 분석

싱글 메타 분석 — 시즌 M-4 리포트

한카리아스 지진 채용률 99.6%가 말해 주는 것. 사용률 상위 30을 유형별로 분류하고, 파티를 짤 때 무엇을 대비해야 하는지 데이터로 풀어봅니다.

 메타 분석

더블 메타 분석 — 시즌 M-4 리포트

더블은 싱글과 완전히 다른 게임. 위협 메타가 만든 대도각참 1위, 트릭룸·순풍·속이기 3축과 날씨 파티까지 채용률 데이터로 분석합니다.

 실전 지식

스피드 실전 가이드 — 라인 표 포함

주요 포켓몬의 무보정·풀노력·최속 실수치 표. 선공 판단법과 스카프·순풍·마비 배율, 동속 처리까지.

 실전 지식

노력치·성격 배분 가이드

챔피언스는 노력치 1 = 실수치 1. 능력치당 32·합계 66이라는 예산을 어디에 쓸지, 배분 패턴 4가지와 조정 개념으로 설명합니다.

 실전 지식

파티 구성 입문

역할 분담 → 약점 겹침 진단 → 메타 대비 → 선출 계획. 이기는 파티를 만드는 사고 과정을 단계별로 따라갑니다.

 실전 지식

실전 메가진화 픽 가이드

종족값 총합이 아니라 "무엇을 얻는가"로 고르는 메가. 유형 3분류와 메가 타이밍, 상대 메가 계산법.

 실전 지식

상태이상·변화기 대응 가이드

도깨비불·하품 루프·앙코르·막말내뱉기 — 상위권일수록 게임을 결정하는 변화기들의 실전 가치와 대응법.

기본 가이드

룰·공식·레퍼런스 — 처음이라면 여기서 시작하세요.

프로그램 사용법

Champions Helper 프로그램 사용법

위력 칩의 색·테두리·숫자가 무슨 뜻인지, 스피드·상대 시점·시뮬레이션 읽는 법, 그리고 화면 인식 영역(빨간 박스)을 맞추는 영역 편집까지 실제 캡처와 함께 설명합니다.

 입문

포켓몬 챔피언스 시작 가이드

게임이 어떤 룰로 굴러가는지 — 싱글 배틀 픽, 레벨 50 고정, 노력치 직접 분배, 타입 상성과 메가진화의 기본을 정리합니다.

 계산

데미지 계산 공식 완벽 정리

실능력치는 어떻게 정해지고, 데미지는 어떤 순서로 계산되는지. 자속·타입 상성·날씨·급소·난수까지 단계별로 풀어봅니다.

 레퍼런스

타입 상성표

18타입이 서로에게 2배·0.5배·0배 중 무엇인지. 공격 타입별로 약점과 강점을 한눈에 정리했습니다.

 레퍼런스

특성·지닌도구 효과

단단한 발톱·철주먹·생명의 구슬·구애 머리띠 등 데미지에 영향을 주는 특성과 도구를 배율과 함께 정리.

 레퍼런스

메가진화 총정리 (75종)

챔피언스에 등장하는 메가진화 전체를, 메가 후 타입·종족값·특성 변화와 함께 표로 모았습니다.
