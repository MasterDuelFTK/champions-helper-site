계산은 프로그램이.

상대 파티를 자동으로 인식해 내 기술의 실시간 데미지와 확정 1타 여부,
교체 시뮬레이션까지 — 배틀에 집중하는 동안 계산은 Champions Helper가 합니다.

⬇ Windows 프로그램 다운로드 📘 도감 보기 도감·계산기는 설치 없이 브라우저에서 · Windows 프로그램은 위 버튼으로 다운로드

게임 화면을 읽고, 데미지를 계산해 보여줍니다

게임 화면의 빨간 영역을 인식해, 위력창에 매 턴 데미지를 자동으로 계산해 표시합니다.

위 두 화면은 서로 다른 배틀에서 캡처한 예시라, 등장하는 포켓몬이 서로 다릅니다. 박스를 환경에 맞추는 방법은 프로그램 사용법 가이드에서 캡처와 함께 설명합니다.

무엇을 해주나요?

화면만 띄워두면, 매 턴 필요한 정보를 알아서 계산합니다.

🔍

상대 파티 자동 인식

화면 OCR로 상대 6마리의 종족·타입을 실시간으로 읽어들입니다. 직접 입력할 필요 없습니다.

⚡

실시간 위력 계산

내 4기술 × 상대 전 포켓몬의 데미지%를 즉시 표시. 확정 1타·난수 1타를 색으로 구분합니다.

🔁

교체·랭크 시뮬레이션

내 포켓몬 교체, 랭크 변화, 지닌도구·노력치·성격을 가정해 위력이 어떻게 바뀌는지 미리 봅니다.

🌦️

날씨·벽·순풍 반영

쾌청·비·모래·싸라기눈, 리플렉터·빛의장막·오로라베일, 순풍을 로그에서 읽어 자동으로 계산에 적용합니다.

✨

메가진화·폼체인지

메가진화 후 종족값·특성·날씨 변화, 돌핀맨 영웅폼, 메타몽 변신, 킬가르도 블레이드폼까지 미리 계산합니다.

🛠️

파티 빌더

종족값·실수치 자동 계산과 노력치 검증. 브라우저에서 파티를 등록하면 프로그램에 바로 반영됩니다.

사용법은 3단계

복잡한 설정 없이, 켜두면 끝입니다.

다운로드 후 설치

받은 설치 파일을 실행하면 관리자 권한 없이 바로 설치되고, 바로가기가 생성됩니다.

포켓몬 챔피언스 실행

게임을 켜면 화면을 인식해 상대 파티와 배틀 상황을 자동으로 추적합니다.

위력창 자동 표시

브라우저에 실시간 위력창이 자동으로 열려 매 턴 필요한 계산을 보여줍니다.

브라우저에서 바로 써보기

프로그램 설치 없이도 쓸 수 있는 도구와 공략이 준비돼 있습니다.

📘

도감

등장 포켓몬의 종족값·타입·특성(한글)을 검색. 메가폼 변화까지 한눈에.
🧮

데미지 계산기

확정 1타 여부와 데미지 범위를 즉시 계산. 브라우저에서 바로 동작.
🛠️

파티 빌더

노력치 배분과 실능력치를 실시간 검증. 프로그램과 연동됩니다.
📖

가이드

배틀 룰부터 데미지 계산 공식까지, 핵심을 한글로 정리한 공략.

지금 바로 시작하세요

Windows용 프로그램을 받아 설치하면, 게임 화면을 자동 인식해 실시간 데미지·교체 시뮬레이션을 시작합니다. 도감·계산기·파티 빌더는 설치 없이 브라우저에서 바로 쓸 수 있습니다.

⬇ Windows용 프로그램 다운로드 (v2.0.4) 🧮 계산기 바로 쓰기
프로그램 요구 사양: Windows 10/11 (64bit) · 포켓몬 챔피언스 화면이 보이는 환경
관리자 권한 없이 설치되며, 바탕화면·시작메뉴 바로가기가 자동으로 생성됩니다.
