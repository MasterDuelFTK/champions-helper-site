무엇을 해주나요?

화면만 띄워두면, 매 턴 필요한 정보를 알아서 계산합니다.

🔍

상대 파티 자동 인식

화면 OCR로 상대 6마리의 종족·타입을 실시간으로 읽어들입니다. 직접 입력할 필요 없습니다.

⚡

실시간 위력 계산

내 4기술 × 상대 전 포켓몬의 데미지%를 즉시 표시. 확정 1타·난수 1타를 색으로 구분합니다.

🔁

교체·랭크 시뮬레이션

내 포켓몬 교체, 랭크 변화, 지닌도구·노력치·성격을 가정해 위력이 어떻게 바뀌는지 미리 봅니다.

🌦️

날씨·벽·순풍 반영

쾌청·비·모래·싸라기눈, 리플렉터·빛의장막·오로라베일, 순풍을 로그에서 읽어 자동으로 계산에 적용합니다.

✨

메가진화·폼체인지

메가진화 후 종족값·특성·날씨 변화, 돌핀맨 영웅폼, 메타몽 변신, 킬가르도 블레이드폼까지 미리 계산합니다.

🛠️

파티 빌더

종족값·실수치 자동 계산과 노력치 검증. 브라우저에서 파티를 등록하면 프로그램에 바로 반영됩니다.

사용법은 3단계

복잡한 설정 없이, 켜두면 끝입니다.

다운로드 후 실행

프로그램을 받아 실행합니다. 설치 과정 없이 바로 켜집니다.

포켓몬 챔피언스 실행

게임을 켜면 화면을 인식해 상대 파티와 배틀 상황을 자동으로 추적합니다.

위력창 자동 표시

브라우저에 실시간 위력창이 자동으로 열려 매 턴 필요한 계산을 보여줍니다.
